# Design Prompt — MSB Smart Solutions

## Full Design Prompt

Design and develop a modern corporate / SaaS / Enterprise Technology landing website for **MSB Smart Solutions**, with **Nexus** positioned as the Main System Platform that connects every smart solution into one ecosystem. The website should be premium, clean, and credible — suitable for enterprise sales, company profile, and future product expansion.

## Brand Direction

- **Company:** MSB Smart Solutions
- **Main platform:** Nexus
- **Slogan:** Connect. Automate. Empower.
- **Voice:** Professional, technical, confident, forward-looking.
- **Key messages:**
  - Powered by Nexus
  - The Main System Platform of MSB Smart Solutions
  - One Platform for All Smart Solutions

## Design Style

- Modern SaaS / Enterprise Technology
- Clean, premium, professional
- Light theme (white background)
- Rounded cards, soft shadows, smooth gradients
- Spacious, airy layout — not crowded

## Color Direction

- Primary: Deep Navy `#0B1B3B`
- Secondary: Brand Blue `#1E63E9`
- Accent: Cyan `#06B6D4`
- Neutrals: White, soft navy tints for borders and muted text
- Status: Emerald for positive growth indicators

## Layout Direction

- 12-column max-width container (`max-w-7xl`)
- Generous section padding (`py-20` / `py-24`)
- Hero: 2-column on desktop, stacked on mobile
- Solutions: 3–4 column grid
- Workflow: 4-column horizontal flow with chevron connectors on desktop
- Solution previews: alternating 2-column layout (text + visual mock)

## UI/UX Goals

- Make Nexus instantly recognizable as the central platform.
- Communicate the breadth of MSB Smart Solutions at a glance.
- Encourage two primary actions: **Request a Demo** and **Contact Sales**.
- Be fully responsive (desktop / tablet / mobile).
- Use motion sparingly (float, animated dashed connector lines) to reinforce the "connected ecosystem" idea.

## Nexus Positioning as Main System Platform

- Nexus is rendered as the **central hub** in the Hero ecosystem visual, with every solution node (WMS, WCS, Traceability, IIoT, BMS, Power, AI, Cloud, Network, Data Center) connected via animated lines.
- A reusable `NexusBadge` reinforces "Powered by Nexus — The Main System Platform of MSB Smart Solutions" throughout the page.
- BMS is included as a first-class node and solution alongside WMS, WCS, Traceability, and IIoT — not as a sub-feature of Power Visualization.
